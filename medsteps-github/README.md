# 医步 MedSteps

医学学习与间隔复习工具，由实际的课程复习需求出发搭建。

医学知识往往散落在不同课件里，读完一遍也不容易判断自己记住了多少。医步把一次复习拆成几个短步骤：先做练习，再独立回忆，最后记录掌握情况并安排下次复习。每张卡片保留来源信息，方便回到原始材料核对。

## 已实现的功能

- 分步练习、提示与答案反馈。
- 独立回忆、自评和间隔复习安排。
- 复习进度保存、暂停后继续及最近一次评价修正。
- 按课程和章节浏览、搜索知识卡片。
- 原始资料页码和摘录追溯，以及受保护的来源图片接口。
- 适配手机屏幕的页面布局。

这是学习工具原型，尚未通过研究验证其学习效果。它不提供诊断或治疗建议。

## 我的工作

我提出医学学习中的具体问题，负责需求梳理、学习步骤与反馈方式的设计，并在使用过程中提出修改意见。代码通过 AI 辅助编程实现；本项目不以独立手写全部代码或训练自有模型为目标。

## 公开版本说明

这个仓库保留应用代码和数据库结构。课程原文、课件图片、个人答题记录、真实学习进度和线上密钥不在仓库中。`lib/initial-sync.json` 中只有一张自行编写的演示卡片；`learning` 数组为空，不会把演示导入当作已经完成学习。

查看演示卡片时可以使用界面里的试练功能。真实课程候选目录及原页图片需要另行导入已获授权的材料；公开版本不附带这些资料。已有线上项目的身份信息也已移除，不会连接到原项目的云端数据库。

## 技术结构

- 前端：React、TypeScript、Tailwind CSS。
- 全栈运行：Vinext / Vite、Cloudflare Workers。
- 存储：Cloudflare D1；来源文件接口支持 R2。
- `app/`：页面、复习交互和 API。
- `lib/review.ts`：卡片校验与复习间隔规则。
- `lib/store.ts`：学习记录、会话与进度保存。
- `lib/access.ts`：访问验证。
- `drizzle/0000_public_schema.sql`：仅含表结构的初始化 SQL。

## 本地运行

需要 Node.js 22.13 或更高版本。先安装依赖并构建：

```sh
npm run install:ci
npm run build
```

在自己的本地环境配置访问凭据（见下文），再初始化本地数据库：

```sh
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_public_schema.sql
npm start
```

访问终端打印的本地地址。`npm run dev` 提供另一个开发模式；其模拟数据库可能使用不同状态目录，不能直接假设与 `npm start` 共享数据。

本仓库从正在使用的项目整理而来。本次整理检查了示例数据、文件范围、数据库结构与源码语法；没有在一台全新电脑上重新部署全部云端服务。

## 环境配置

将以下值保存在本地忽略文件 `.dev.vars` 或部署平台的秘密变量中，勿提交到 GitHub：

- `ADMIN_SYNC_TOKEN`：管理员同步令牌。
- `PHONE_SESSION_SECRET`：会话签名用随机秘密值。
- `PHONE_UNLOCK_VERIFIER`：访问口令的 PBKDF2 校验值，其格式与生成规则见 `lib/access.ts`。
- `OWNER_EMAIL`：可选的所有者标识。

`.openai/hosting.json` 仅保留通用的 `DB` / `BUCKET` 绑定名称；云端部署时需使用自己的数据库、存储和项目配置。
