# 第三方代码说明

本项目使用 React、Vinext、Vite、Cloudflare 工具链和其他 npm 依赖，具体版本见 package.json 与 package-lock.json。依赖分别适用其原有许可。

`build/sites-vite-plugin.ts` 的配套许可保留于 `build/sites-vite-plugin.LICENSE`。

`vendor/shadcn-tailwind-4.13.0.css` 的配套许可保留于 `vendor/shadcn-tailwind-4.13.0.LICENSE.md`。

仓库中通用构建、连接器及运行支持文件来自原项目使用的基础模板，不计作项目维护者独立创作的业务代码。
